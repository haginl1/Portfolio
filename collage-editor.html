📖 How to Use

  • Add Images: Click "➕ Add Images" to upload photos. You can select multiple at once.
  • Edit Mode (✏️): Tap any image to select it. Use the controls to zoom, pan left/right, and pan up/down to position the image exactly as you want.
  • Arrange Mode (↔️): Switch to "Arrange" mode to reorder images by tapping a position then tapping another to swap them.
  • Replace Images: Select an image and click "📷 Replace" to swap it with a different photo.
  • Style & Layout: Choose your preferred filter (Natural, MCM, B&W, Warm B&W) and select your layout size (20×16, 16×20, or 8×10).
  • Generate Print: Click "🖼️ Generate 300 DPI Print" to create a high-quality print-ready file (6000×4800px or 4800×6000px).
